# 🎮 Rock-Paper-Scissors Game

A simple and interactive **Rock-Paper-Scissors game built with Python**.

The user plays against the computer, which randomly selects Rock, Paper, or Scissors. The game determines the winner, keeps track of scores, and allows the user to play multiple rounds.

---

## 📌 Features

- 🎮 Play Rock, Paper, or Scissors against the computer
- 🤖 Computer makes a random choice
- 🏆 Automatically determines the winner
- 📊 Tracks user and computer scores
- 🔄 Supports multiple rounds
- ❌ Handles invalid user input
- 🛑 Allows the player to stop the game
- 🎉 Displays the final winner
- 💻 Simple command-line interface

---

## 🛠️ Technologies Used

- **Python 3**
- `random` module
- Conditional statements
- While loops
- User input
- Variables
